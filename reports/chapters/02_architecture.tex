\chapter{Architecture}
\chapterlead{One warehouse, three layers, five runners: the whole system on two pages.}

\begin{glance}
\item MongoDB (operational) \textrightarrow{} PostgreSQL \file{walmart_db} (bronze \textrightarrow{} silver \textrightarrow{} gold) \textrightarrow{} dashboard and reports.
\item Every layer hand-off is a quality gate; a failed gate stops the run.
\item The same eight stages run on Windows, in Docker, on Airflow and from Make.
\end{glance}

Consumers (Streamlit dashboard, \file{sql/analytics}, \file{reports/}) read gold only.

\section{Infrastructure view}

Postgres is \file{walmart_db}; schema names default to \file{bronze}/\file{silver}/\file{gold} through \file{POSTGRES_SCHEMA_*} in \file{.env}, read once by \file{src/utils/engine.py}. All runners set \file{PYTHONPATH} to the project root so \file{src.*} resolves identically. The localhost rule (\file{docs/architecture.md}): \file{.env} keeps \file{localhost} for local \cmd{uv run}; only containers rewrite to \file{host.docker.internal} in the DAG preamble and entrypoint. \file{.env} itself is never edited.

\begin{keybox}
\item Bronze mirrors, silver cleans, gold models; consumers read gold only.
\item Gates between layers fail the run; nothing half-promoted ever lands downstream.
\item One \file{.env}, validated once, shared by every runner and the app.
\end{keybox}
